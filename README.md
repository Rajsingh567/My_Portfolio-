## 📌 About the Project

This is a fully responsive and interactive portfolio website built to highlight:

* Technical skills
* Real-world projects
* Leadership experience
* Certifications & education
* Contact and networking

The design focuses on **premium UI/UX**, smooth animations, and a futuristic developer aesthetic.
